# Theme and Wording

## Visual theme

Graveyard and dungeon. Dark, calm, readable.

Spooky elements must support the function, not decorate.

## Lifecycle vocabulary

Used in code and UI:
- **alive**
- **weak**
- **dead**
- **resurrected**

Use **tend** for acting on an item.

Use **graveyard** for the list of dead items.

## Interface text

Plain and short. No jargon.

## Accessibility

- Keyboard usable
- Readable contrast
- Respect `prefers-reduced-motion` settings
- Never show state by color alone

## Assets

Only original or openly licensed assets and fonts. No third-party logos.
